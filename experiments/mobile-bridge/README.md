# Individual self-send bridge (.52)

Publicly accessible interface, private session per visitor. No shared operator token, no fixed account, no /v1 route. Set TURNSTILE_SITE_KEY and TURNSTILE_SECRET_KEY for a Turnstile widget restricted to poldkent.github.io (action sonoro_link) and PUBLIC_BRIDGE_ENABLED=true in Render only after reviewing tests and security. Otherwise /health reports publicEnabled:false and pairing/send endpoints reject. Old BRIDGE_* variables are unused; remove from Render. Keep the importer separate.

Only an owned linked account may send to its verified own phone JID. Do not enter anyone else's number or share pairing codes. No SMS/PIN/password collection. The unofficial linked device has potential account access even though the code disables full history sync and has no inbox feature. Temporary credentials, best-effort logout, manual unlinking required. Two concurrent sessions, 6 link requests per 10 minutes and one per number; 5 sends/15 minutes; 1 MB combined. Public activation and first .49 self-chat send confirmed by operator; simultaneous multi-user isolation is not independently verified. Do not promote as official or unlimited. Audit security and privacy before public launch.

En español: cada usuario introduce su propio número y autoriza su dispositivo temporal. No hay clave del administrador ni destinatario fijo. Para habilitar el servicio configura Turnstile y las tres variables anteriores. El primer autoenvío .49 fue confirmado por el operador. Verifica además dos cuentas propias simultáneas, aislamiento, recepción con audio, cierre y eliminación del dispositivo. No uses cuentas ajenas.
